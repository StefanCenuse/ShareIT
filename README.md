# ShareIT

Platformă web pentru donarea și reutilizarea obiectelor. Utilizatorii publică obiecte disponibile, iar alți utilizatori pot trimite solicitări. Aplicația urmărește disponibilitatea obiectelor și istoricul donațiilor.

Proiect individual pentru materia Programare Multimedia (UPT).

## Pagini
- index.html: pagina principală
- catalog.html: lista obiectelor, cu căutare și filtre
- obiect.html: detalii despre un obiect
- publica.html: formular de publicare a unui obiect
- cont.html: autentificare, obiectele mele, solicitări, istoric donații

## Tehnologii
HTML5, CSS3, Bootstrap 5.3 (CDN), Google Fonts (Sora, Nunito Sans). Etapele următoare adaugă JavaScript și o bază de date.

## Rulare
Descarcă sau clonează repository-ul și deschide index.html în browser (sau folosește extensia Live Server din VS Code). Este nevoie de conexiune la internet pentru Bootstrap și fonturi.

## Stadiu
Etapa 1: structura aplicației, wireframe-uri (docs/wireframes) și pagina principală. Celelalte pagini sunt momentan simple pagini în lucru.
